
# Backend Control de Torneos de Futbol

Permite la gestion de un torneo de futbol y todo lo que este implique ya sea profesional o aficionado, esta orientado para que cualquier organizacion lo pueda utilizar debido a su sencilles y simplicidad 


## Tecnologias

**Framework:** Laravel version 12 

**Autenticacion:** Laravel-Sanctum

**Notificaciones:** Firebase


## Features

- Autenticacion y asignacion de roles
- Registro de Representante del torneo
- Registo de Torneo
- Registo de encargado de equipo
- Registo de jugdores por equipo
- Registo de estaditicas por partido
- Registro de estaditicas por torneo
- Reset de torneo
- Notificaciones con firebase
